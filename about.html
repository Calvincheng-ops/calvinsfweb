A LITTLE ABOUT ME

从理解业务，
到动手实现。

我的专业连接技术与管理。在实习中，我处理过业务数据，开发过运费计算模块，也从零搭建过飞书业务系统。现在，我在字节跳动飞书商业化团队实习，参与 AI 场景沟通、Demo 演示与培训。

我习惯把一个模糊的问题拆成流程、数据和具体操作，再用原型、脚本或可交互的应用验证它。Claude Code 和 Codex 是我常用的开发助手，SQL、Python、飞书和 API 是我把想法落到实际工作中的工具。

工作之外，我喜欢摄影、旅行与记录生活。学生会和校园活动让我学会了与不同的人协作，也让我越来越重视把事情讲清楚、推进下去。
